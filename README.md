# **🛒 E-Commerce Product Catalog**



Built a full-stack product catalog application

Backend developed using **Spring Boot, JPA, Hibernate, MySQL**

Frontend developed using **React (Vite) and Bootstrap**

Implemented Category–Product relationship

Created REST APIs to fetch products and categories

Added category filter, search, and price sorting

# Api and EndPoints

| Method | Endpoint                      |
| ------ | ----------------------------- |
| GET    | `/api/products`               |
| GET    | `/api/categories`             |
| GET    | `/api/products/category/{id}` |
